## O projektu
NSN Garden je moderna i responzivna web aplikacija za online cvjećaru izrađena korištenjem čistih web tehnologija. Cilj projekta je omogućiti korisnicima jednostavan pregled cvjetnih aranžmana, buketa i dekoracija kroz estetski privlačan i funkcionalan dizajn. Web stranica sadrži naslovnu sekciju sa promotivnim sadržajem, katalog proizvoda sa naprednim filterima, kontakt formu sa validacijom, te je implementirana kao progresivna web aplikacija (PWA) sa podrškom za offline rad.

## Tehnologije
- HTML5 (Semantički tagovi)
- CSS3 (Custom Properties, Flexbox, Grid - bez frameworka)
- JavaScript (Vanilla JS - bez biblioteka)
- PWA API (Service Worker i Application Manifest)

## AI alati koristeni u projektu
- **Gemini (AI Asistent):** - **HTML:** Pomoć pri strukturiranju čistih semantičkih tagova unutar formi i kartica proizvoda.
  - **CSS:** Optimizacija medijskih upita (`@media`) i rješavanje konflikata u layoutu za responzivni prikaz na mobilnim telefonima.
  - **JavaScript & PWA:** Pomoć pri postavljanju *Network-First* logike keširanja unutar `sw.js` fajla i strukture za `manifest.json`.
  - **Slike i grafika:** Korišten za generisanje autorskih, visokokvalitetnih slika asortimana unutar `images/` foldera radi izbjegavanja autorskih prava.

## Napomene
Sve grafike, ikonice i vizuelni identitet aplikacije kreirani su uz pomoć AI generisanja slika u visokoj rezoluciji. Web aplikacija je u potpunosti prilagođena različitim uređajima kako bi korisničko iskustvo bilo kvalitetno na računarima i na mobilnim telefonima, te je uspješno testirana za instalaciju na početni ekran uređaja (Add to Home Screen).
